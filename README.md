# Nguyen Tien Thanh — Personal Portfolio (Option 2)

A responsive personal portfolio starter for the **Design Sketch demo for a site coded from a template** assignment. The layout is organized as a reusable portfolio template that can be customized with personal content, projects, and contact information. It uses plain HTML, CSS, and JavaScript and can be published directly with GitHub Pages (no build step or external dependencies).

## Files

- `index.html` — portfolio page and section structure.
- `styles.css` — responsive styles for phones, tablets, and larger screens.
- `script.js` — mobile navigation and a demo contact form that opens the visitor's email app.
- `assets/portfolio-wireframes.png` — combined black-and-white wireframe image shown on the site.
- `submission/mobile-wireframe.png` — image for the assignment's **mobile view** upload field.
- `submission/larger-screen-wireframe.png` — image for the assignment's **larger screen view** upload field.
- `submission/portfolio-wireframes-combined.png` — both sketches together in one image.
- `submission/brief-write-up.txt` — ready-to-paste assignment title and brief description for Option 2.
- `submission/COURsera-SUBMISSION-GUIDE.md` — quick submission checklist.

## Customize the template

1. Replace the sample email `thanh@example.com` in `index.html` and `script.js` with your own preferred contact address.
2. Replace the sample project cards with your real projects as they become available.
3. Adjust the About and Skills text to match your experience.
4. Preview the page at both mobile and desktop widths and test the mobile menu.

## Publish with GitHub Pages

1. Create a new repository on GitHub. A repository named `your-username.github.io` publishes at the root domain; another repository is published at `https://your-username.github.io/repository-name/`.
2. Extract this ZIP and upload the **contents** of the `personal-portfolio-nguyen-tien-thanh` folder to the repository root. Make sure `index.html` is at the root, not one folder deeper.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to finish deploying. The published URL will appear in **Settings → Pages**.

GitHub Pages can publish this static site, but the sample contact form does not send or store messages on a server; it prepares a message using the visitor's default email app.
